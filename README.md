# 🟢 Ben 10: Omnitrix Protocol

A fan-made **Ben 10 browser action game** built using HTML5 Canvas, CSS, and JavaScript.

## 🎮 Play the Game

👉 **[PLAY NOW](https://YOUR-USERNAME.github.io/omnitrix-protocol/)**

> Replace `@skbalaji-07` with your GitHub username after enabling GitHub Pages.

## ⚡ Features

* 🟢 4 Alien Transformations

  * Heatblast
  * XLR8
  * Four Arms
  * Diamondhead
* ⚔️ Real-time combat
* 👾 Multiple enemy types
* 💥 Boss battle against Vilgax
* 📖 Story Mode with 3 chapters
* 🔥 Hero Mode
* ⚡ Omnitrix energy system
* 🎯 Combo & scoring system
* 🔊 Web Audio sound effects
* 📱 Touch controls
* 💾 Local progress saving
* ✨ Canvas particle effects

## 🕹️ Controls

| Action    | Keyboard            |
| --------- | ------------------- |
| Move      | `A / D` or `← / →`  |
| Jump      | `W` / `↑` / `Space` |
| Attack    | `J`                 |
| Transform | `1` `2` `3` `4`     |
| Revert    | `R`                 |
| Pause     | `P`                 |

## 🧬 Alien Forms

| Alien          | Specialty                |
| -------------- | ------------------------ |
| 🔥 Heatblast   | Fire-based attacks       |
| ⚡ XLR8         | High speed               |
| 💪 Four Arms   | Heavy attacks            |
| 💎 Diamondhead | Defense & ranged attacks |

## 📖 Story

### Chapter 1 — Strangers in Bellwood

Fight incoming enemies and discover the threat.

### Chapter 2 — Ambush on the Highway

Survive increasingly difficult enemy waves.

### Chapter 3 — The Conqueror's Deck

Face the final boss: **Vilgax**.

Complete Story Mode to unlock **Hero Mode**.
