## 📌 About The Project

**Ben 10: Omnitrix Protocol** is a fan-made browser action game inspired by the Ben 10 universe.

The project was built from scratch using **HTML5 Canvas and JavaScript**, without relying on a game engine. It features alien transformations, enemy combat, multiple story chapters, a boss battle, an Omnitrix energy system, and an endless Hero Mode.

The project demonstrates practical skills in **JavaScript game development, Canvas rendering, animation, collision detection, game-state management, procedural effects, browser audio, and responsive controls.**

## 📖 Story

### Chapter 1 — Strangers in Bellwood

A strange device falls near Bellwood and attaches itself to Ben's wrist.

Soon after, hostile drones arrive looking for the Omnitrix.

**Objective:**

> Hold the street and survive the attack.

### Chapter 2 — Ambush on the Highway

The Rust Bucket is attacked while traveling through the desert.

New armored enemies appear, requiring stronger close-range combat.

**Objective:**

> Protect the Rust Bucket.

### Chapter 3 — The Conqueror's Deck

Ben and the team are taken aboard Vilgax's flagship.

The final battle begins.

**Objective:**

> Clear the deck and defeat Vilgax.

### Hero Mode

Complete the story to unlock **Hero Mode**, an endless survival mode where enemy waves continue to increase.

## 🎯 Controls

### Keyboard

| Key                 | Action        |
| ------------------- | ------------- |
| `A` / `←`           | Move left     |
| `D` / `→`           | Move right    |
| `W` / `↑` / `SPACE` | Jump          |
| `J` / `Z`           | Attack        |
| `Q`                 | Revert to Ben |
| `1`                 | Heatblast     |
| `2`                 | XLR8          |
| `3`                 | Four Arms     |
| `4`                 | Diamondhead   |
| `P`                 | Pause         |

### Mobile / Touch

The game also provides touch controls for movement, jumping, attacking, and transformation.

* Health and damage systems

* Transformation state management

* Particle effects
